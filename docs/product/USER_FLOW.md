# Fluxo Principal do Usuário

## Objetivo

Permitir que um analista transforme atendimentos históricos em conhecimento estruturado para evolução da Base de Conhecimento do Visus.

---

# Fluxo Principal

Login

↓

Dashboard

↓

Selecionar Projeto existente
ou
Criar novo Projeto

↓

Selecionar Solução Visus

↓

Criar nova Análise

↓

Enviar atendimentos

↓

Selecionar Base de Conhecimento correspondente

↓

Executar análise

↓

Visualizar resultados

- Insights
- Indicadores
- Lacunas documentais
- Problemas de encontrabilidade
- Sugestões de melhoria

↓

Gerar Plano de Melhoria

↓

Revisão humana

↓

Salvar Projeto

↓

Exportar resultados (opcional)

---

# Regras

Toda análise pertence obrigatoriamente a um Projeto.

Todo Projeto está associado a uma Solução Visus.

Cada análise utiliza apenas uma Base de Conhecimento.

Nenhuma recomendação é aplicada automaticamente.

Toda melhoria depende de validação humana.
