# ADR-001

## Status

Accepted

## Context

O sistema Visus Knowledge Intelligence será desenvolvido utilizando arquitetura Feature-First.

O objetivo é organizar o código por domínio de negócio, facilitando manutenção, escalabilidade e isolamento de funcionalidades.

## Decision

A estrutura principal da aplicação será organizada por features.

A pasta `src/app` conterá exclusivamente:

- rotas;
- layouts;
- providers específicos do App Router.

Toda regra de negócio deverá permanecer dentro de `src/features`.

Componentes compartilhados permanecerão em `src/components`.

## Consequences

Benefícios:

- alta coesão;
- baixo acoplamento;
- facilidade para evolução do sistema;
- organização consistente.

Desvantagens:

- exige disciplina arquitetural;
- pequenas funcionalidades podem parecer inicialmente mais estruturadas que o necessário.
