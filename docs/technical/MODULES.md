# Módulos do Sistema

## Dashboard

Responsável por apresentar:

- projetos recentes;
- últimas análises;
- indicadores gerais;
- atividades recentes.

---

## Projetos

Responsável por:

- criar projetos;
- editar projetos;
- listar projetos;
- arquivar projetos.

Cada Projeto representa um contexto completo de trabalho.

---

## Análises

Responsável por:

- iniciar análises;
- selecionar solução Visus;
- selecionar Base de Conhecimento;
- receber atendimentos;
- controlar execução da IA.

---

## Insights

Responsável por apresentar os conhecimentos extraídos.

Exemplos:

- dúvidas recorrentes;
- artigos ausentes;
- artigos incompletos;
- oportunidades de melhoria;
- problemas de taxonomia.

---

## Planos de Melhoria

Responsável por organizar ações derivadas das análises.

Cada plano poderá conter:

- novos artigos;
- revisões;
- consolidações;
- reorganizações.

---

## Biblioteca

Responsável por consultar:

- Bases de Conhecimento;
- artigos;
- histórico documental.

---

## Configurações

Responsável por:

- parâmetros do sistema;
- modelos de IA;
- configurações gerais;
- preferências do usuário.
