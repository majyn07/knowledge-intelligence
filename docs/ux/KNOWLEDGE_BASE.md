# Base de Conhecimento

## Objetivo

Gerenciar as Bases de Conhecimento utilizadas pelo Visus Insights durante as análises.

A Base de Conhecimento armazenada no Visus Insights representa uma cópia da documentação oficial utilizada exclusivamente como contexto para a IA.

A edição da documentação continua sendo realizada na plataforma oficial.

---

## Responsabilidades

A Base de Conhecimento permite:

- importar novas versões da documentação;
- visualizar informações da base importada;
- consultar os artigos disponíveis;
- acompanhar histórico de importações;
- disponibilizar contexto para as análises.

Não é responsabilidade desta funcionalidade editar artigos.

---

## Fluxo

Base de Conhecimento

↓

Selecionar solução

↓

Visualizar informações da Base

↓

Consultar artigos

↓

Visualizar artigo

---

## Informações exibidas

Cada Base deverá apresentar:

- solução;
- origem;
- versão;
- data da importação;
- quantidade de artigos;
- status.

---

## Ações

Cada Base deverá possuir:

- Ver artigos;
- Importar nova versão;
- Visualizar histórico.

---

## Importação

Uma nova importação substitui a Base utilizada nas próximas análises.

As análises já realizadas permanecem vinculadas à versão da Base utilizada durante sua execução.

---

## Artigos

Cada artigo deverá possuir, no mínimo:

- identificador;
- título;
- solução;
- URL original (quando disponível).

---

## Relação com as análises

Durante uma análise, a IA utiliza exclusivamente a Base correspondente à solução do atendimento.

As recomendações deverão referenciar explicitamente os artigos existentes da Base importada.

---

## Princípios

A Base de Conhecimento do Visus Insights não é a documentação oficial.

Ela representa um espelho da documentação oficial utilizado para fornecer contexto às análises executadas pela IA.

A documentação oficial permanece sendo a única fonte de verdade.
