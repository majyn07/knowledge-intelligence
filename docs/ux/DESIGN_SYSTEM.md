# Design System

## Objetivo

Criar uma interface limpa, moderna e focada em produtividade.

A interface deve transmitir confiabilidade, organização e análise de dados.

---

# Estilo

- Minimalista
- Corporativo
- Baixa distração
- Alta legibilidade

---

# Tema

Light por padrão.

Dark Mode será suportado futuramente.

---

# Tipografia

Fonte padrão:

Geist

---

# Bordas

Radius médio.

Componentes discretamente arredondados.

---

# Sombras

Poucas.

Somente para destacar cartões importantes.

---

# Espaçamento

Utilizar escala consistente.

Priorizar áreas respiradas.

---

# Componentes

Utilizar prioritariamente componentes do shadcn/ui.

Evitar criação de componentes personalizados quando existir equivalente oficial.

---

# Cores

Primária:
Azul

Neutras:
Slate

Sucesso:
Verde

Aviso:
Âmbar

Erro:
Vermelho

Informação:
Azul

---

# Filosofia

Os dados são mais importantes que os elementos gráficos.

A interface nunca deve competir com o conteúdo.
