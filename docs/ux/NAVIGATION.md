# Navigation

## Filosofia

A navegação deve ser contínua.

O usuário deve sentir que permanece dentro do mesmo ambiente de trabalho.

Sempre que possível, apenas o conteúdo central será alterado.

---

# Estrutura

Header Global

↓

Sidebar

↓

Workspace

↓

Painel Contextual

---

# Sidebar

Responsável pela navegação principal.

Itens previstos:

- Dashboard
- Análises
- Plano de Melhoria
- Biblioteca
- Indicadores
- Importações
- Exportações
- Configurações

---

# Header

O Header apresenta o contexto atual.

Exemplos:

Workspace > Análises

Workspace > Biblioteca

Workspace > Indicadores

O Header também poderá conter:

- busca global;
- notificações;
- perfil;
- ações rápidas.

---

# Navegação Secundária

Cada módulo poderá possuir sua própria navegação.

Exemplo:

Análises

- Todas
- Em andamento
- Concluídas
- Arquivadas

---

# Navegação Contextual

Sempre que necessário, um painel lateral exibirá informações adicionais sem retirar o usuário da tela atual.

Exemplos:

- propriedades;
- detalhes;
- histórico;
- artigos relacionados;
- comentários.

---

# Breadcrumb

O breadcrumb representa apenas o contexto.

Ele não substitui a Sidebar.

Exemplo:

Workspace

>

Análises

>

Análise #145

---

# Histórico

Sempre preservar:

- filtros;
- pesquisa;
- paginação;
- ordenação;
- seleção atual.

O botão "Voltar" do navegador deve funcionar naturalmente.

---

# Ações

Operações importantes devem ocorrer dentro do Workspace.

Evitar abrir novas páginas ou novas abas.

Priorizar:

- drawers;
- sheets;
- painéis laterais;
- diálogos.

---

# Responsividade

Desktop:

Sidebar fixa.

Tablet:

Sidebar recolhível.

Mobile:

Sidebar temporária.
